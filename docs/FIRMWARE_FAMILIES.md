# 1.11 / 1.20 与配置迁移

公开版共用一套编辑界面，固件实际内容决定可用功能。选择器用来核对导入预期，不能把 1.11 二进制改名成 1.20。

| 输入 | 支持范围 |
| --- | --- |
| 已识别的官方 1.11 与公开版 1.11 客制包 | 沿用背景、裁切、滤镜、XMP 与版本历史功能 |
| 其他通过结构核验的 1.11 | 沿用原有保留资源的版本重包；未知功能布局不开放原生写入 |
| 官方 1.20，内部版本 1.20.10.11 | 背景、裁切、滤镜、画意开关；完整包指纹与布局核验后编译 |
| 本版生成的 1.20 产品固件 | 从嵌入资源、原生目录和恢复记录读回，在新电脑继续编辑 |
| 其他 1.20／历史研究候选 | 不视为可续编的公开产品格式 |

官方 1.20 完整输入 SHA256 为 `7563d7e462f0c53b6ab2fbab7cdfbbb57151a41192ee82f4f3a2108f9d77650d`。固件由用户提供，源码不附原厂或客制 BIN。

## 迁移流程

1. 导入 1.11 客制固件，或打开其编辑记录。先完成尚未结束的 XMP 颜色转换。
2. 点击“一键迁移到 1.20”，选择官方原版 1.20 BIN。
3. 工具保存原草稿，创建新的 1.20 记录，保留可支持的滤镜颜色／图标／参数与显隐顺序、裁切比例及历史身份、关机素材／名称／显示方式／列表顺序。
4. 检查新记录，按平常方式保存和生成。可以继续增加或修改内容。

两版原厂共有滤镜沿用目标版本资源，保留用户显隐／排序；1.20 新原厂项目保留。自定义颜色 payload 重新写入 1.20 的原生描述符，内部资源编号按目标目录分配，不携带旧程序地址。已移除的滤镜和裁切仍可保留历史身份，避免重新解释旧照片。

这项操作只迁移编辑器能够识别的配置，不复制相机机身里的 UserMode、当前选中滤镜、关机图案或其他设置，也不把旧版评分、影集、AF 或柔光代码带入新固件。缺少已识别布局、素材或容量不足时会报出原因，不生成部分迁移的成功结果。

## 画意摄影

1.20 滤镜页的画意摄影开关默认关闭。它控制原厂未开放的 style 31 入口，并接入原生 Mono Standard 灰度处理。此前研究没有确认其包含完成的独立画意像素效果，开启不保证出现与普通黑白不同的质感。

开关独立于原厂 Mono 解锁；不会顺带开启六项旧 Mono 滤镜、晒化或 AF 实验。官方其他功能保持。

## 续编、回退和验证

1.20 产品产物使用独立 `GR4P1201` 恢复记录；旧研究记录 `GR4R1201` 不自动成为可编辑产物。重新导入会核对正文、原生目录、颜色与图片资源，并核验原厂基线恢复。编辑备份仍需相同输入 BIN；备份本身不含固件。

版本号和历史回退按家族分开分配。历史回退保留选定目标的程序和资源，只处理版本、校验及用户请求的低版本策略；跨家族升级使用配置迁移入口。

当前已验证容量为 16 项活动自定义滤镜、57 个保留滤镜身份、250 项自定义裁切身份和 16 张关机图片；这是编译／离线检查边界，不是实测相机容量。身份不会因删除而回收，耗尽时需新建基础项目。

离线编译、容器解码、原生 ARM 受控执行与资源读回不等于相机刷入、启动、JPEG／DNG 实拍或自动对焦硬件通过。安装和实际效果仍需设备验证；macOS 未经过实机验收。
