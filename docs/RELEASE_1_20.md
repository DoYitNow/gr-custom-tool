# 双版本编辑与迁移验证（2026-10-26）

本次公开快照只增加背景、裁切、滤镜、画意开关的 1.20 产品路径，以及 1.11 客制配置迁移。保留原公开版 1.11 writer、项目 edition、XMP 与校色链路。产品实现来自开发核心选定快照；没有同步研究 Git 历史、评分／影集、AF 实验或柔光功能。

## 操作

重新启动 `start.cmd` 或 `start.sh`。导入可选择自动识别、1.11 或 1.20。已打开 1.11 项目时，点击“一键迁移到 1.20”，选择官方 1.20，再检查并生成。原项目保留。详细边界见 [FIRMWARE_FAMILIES](FIRMWARE_FAMILIES.md)。

画意摄影默认关闭。开启后接入原厂未开放入口和 Mono Standard 灰度路径，不能把它当作已完成的独立画意效果。

## 离线验证

- 当前公开测试共 208 项，204 项通过，4 项因环境／输入条件跳过；没有失败或错误。
- 另使用真实官方 1.20 做 4 项拟合上下文检查，均通过；确认 XMP 链路读取 1.20 的实际颜色表。
- 官方 1.20 默认配置、单独画意、滤镜＋2.35:1 裁切＋背景＋画意组合均完成实际 ARM 装配和资源读回。
- 组合固件完成容器校验、新鲜解码、全新数据目录重新导入、修改后再次生成、低版本支持开／关及官方历史回退。
- 实际 1.11 `.97` 的 9 项自定义滤镜、4 项活动自定义裁切和 2 张关机图迁移至 1.20；三硬件 bank 的五类颜色 payload 逐字节一致，原编辑记录保持。
- 连续编辑保留退役滤镜 34 和裁切 7，新项分配 35 与 8，旧颜色保持。JSON 备份可恢复这些数据上下文，无需依赖另一份候选 BIN 或本地账本。
- 没有旧 public5 裁切时保留原厂八条比例指令；迁移该身份时保留既有 2.35 对焦修正，受控 ARM 检查覆盖对焦框及模式 0／14／15。

208 项测试包含对编译／存储／HTTP 边界的替身检查，不全是实际固件运行；上列真实输入检查另有本地 ignored 记录。校验及受控 ARM 执行不等于设备刷入、启动、实际像素、镜头动作、实拍或完整硬件通过。此次没有写相机或 SD 卡，macOS 尚未实机验收。
