# 滤镜校色

公开版使用完整 Look/Profile XMP 和 GR IV DNG 生成候选滤镜资源。“转换方式”默认 **本地模拟**；Windows 上可选 **Lightroom Classic** 生成目标 JPEG。两条链路随后使用同一套软件域拟合规则。生成文件只经过离线检查，机内颜色和刷入结果仍需实测。

## 默认样片

全新数据目录首次使用时，程序将仓库内作者提供的 `R0000289.DNG`、`R0000351.DNG`、`R0000398.DNG` 复制到用户数据目录，前两张参与拟合，`R0000398.DNG` 用作独立检查样片。已有 `dataset.json` 不会被覆盖；若已登记别的样片，继续使用原登记。仓库不附原厂 BIN、JPEG 样片或 XMP 预设。

你也可以在校色设置中一次选择至少 3 张自己的兼容 GR IV DNG，指定其中 1 张为独立检查样片，然后保存。独立检查样片不参加拟合。覆盖不同光线、肤色、植被、暖色和中性物体更利于发现模型偏差；3 张只满足启动条件，不保证任意 XMP 的色彩效果。

## 导入与转换

1. 导入通过结构校验的 GR IV `1.11.10.x` BIN。在“滤镜”中从原厂滤镜复制出可编辑槽位；原厂槽位本身只读。只有布局已核验的输入会开放滤镜资源写入。
2. 先在色彩区“设置 → 转换方式”选默认“本地模拟”或 Windows 上的“Lightroom Classic”，再向自定义槽位导入包含完整颜色数据的 Look/Profile XMP；导入即启动转换。已有 XMP 切换方式时须点击“重新转换”。普通 Develop 调整、仅引用外部 Look 的文件及局部调整不能完整转换。
3. 等待目标渲染与拟合完成，查看独立检查样片预览和拟合报告。
4. 需要生成完整 BIN 时，再配置 LLVM 工具链并按普通生成流程导出。

### 本地模拟（默认）

程序用 LibRaw/OpenCV 近似渲染 DNG 与 XMP 的目标，不调用 Lightroom。默认色调和 Gamma 数值资源随程序提供；这条链路没有完整重现 Adobe Develop 或相机 ISP。

### Lightroom Classic（Windows 可选）

先在 Windows 安装并自行打开 Lightroom Classic。选择此方式并提交转换后，程序准备桥接插件与本次请求；在 Classic 的 **增效工具管理器** 启用 **GR4 Firmware Bridge**，等待它导出本次 DNG 的目标 JPEG。程序不会自动启动 Classic；未连接时任务会保持等待状态。目标 JPEG 仍须经过本项目的软件域拟合才能成为候选机内资源。

目前桥接接口与离线回执检查已接入，尚未完成真实 Lightroom 渲染或相机实测。即使报告误差较低，也不能证明机内最终效果、刷入或设备稳定性。

算法与数值资源边界见[校色数值链路](CALIBRATION_NUMERIC.md)，完整界面步骤见[使用指南](USAGE.md)。
