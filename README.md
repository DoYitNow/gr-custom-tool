# 固件编辑器

**gr-custom-tool** 是一款在本机浏览器中运行的编辑工具。公开版负责固件容器读取、写入、版本策略和回退文件生成；在已核验的 GR IV 布局上，也可写入裁切、关机画面和滤镜资源。XMP 解析与颜色拟合沿用研究版规则。

[快速开始](#快速开始) · [使用指南](docs/USAGE.md) · [校色说明](docs/CALIBRATION.md) · [常见问题](#常见问题) · [支持作者](#support) · [使用协议](web/terms.html)

## 功能

| 功能 | 当前状态 |
| --- | --- |
| 裁切比例 | 新增自定义比例、预览、命名和排序 |
| 关机画面 | 导入图片、预览、选择显示方式、管理图案 |
| 编辑记录 | 保存草稿、导入与导出编辑备份 |
| 版本历史 | 查看版本与来源、载入编辑、生成回退文件 |
| 低版本固件更新 | 生成时可选择支持刷回低版本固件；默认开启 |
| 滤镜与 XMP | 导入完整 Look/Profile XMP；默认本地模拟，Windows 可选 Lightroom Classic 生成目标，再拟合候选颜色资源 |

本工具只生成文件，不会自动刷写设备。仓库不提供原厂固件、JPEG 样片或第三方 XMP；作者提供的 3 张 GR IV DNG 用于本地近似校色。

## 兼容范围

- **可生成：**通过完整容器、节布局、版本一致性和校验核验的 GR4 `1.11.10.x` BIN 均可导入并生成保留资源的版本/回退候选；已适配的官方原版 `1.11.10.7` 与当前公开版候选还支持裁切、关机画面和滤镜资源写入。
- **功能差异：**未登记布局的输入仍可保存、改版本和生成候选，但会保留原有裁切、关机、图标和无法识别的版本策略，不开放未经核验的原生写入。已识别的版本策略才会响应“支持刷回低版本固件”开关。
- **电脑：**Windows x64、macOS Apple Silicon / Intel；均需 64 位 Python **3.12**。

官方输入按文件内容识别，仅版本号相同不足以确定兼容性。当前公开版尚未完成独立端到端及实机验收，macOS 尚未实机验证；文件生成成功不代表刷入、启动或设备功能正常。

## 快速开始

### 1. 准备环境

安装 **64 位 Python 3.12**，下载源码并解压到可写目录。GitHub 发布后，可在仓库页面选择 **Code → Download ZIP** 获取源码。

生成文件还需要 LLVM 工具链，首次配置方法见[使用指南](docs/USAGE.md#安装与启动)。编辑前不必先配置 LLVM。

### 2. 启动工具

| 系统 | 操作 |
| --- | --- |
| Windows x64 | 双击项目目录中的 `start.cmd` |
| macOS | 在项目目录打开终端，运行 `sh start.sh` |

首次启动会自动创建 `.venv` 并安装固定版本的 Python 依赖，需要联网。滤镜本地校色还需要 `numpy`、`rawpy`、`opencv-python-headless` 和 `capstone`；启动器会检查这些模块。随后自动打开浏览器；默认地址为 `http://127.0.0.1:8787`，端口被占用时会更换，请以启动窗口显示的网址为准。

关闭启动窗口或按 `Ctrl+C` 停止服务。下次运行同一启动器即可继续使用。

### 3. 完成第一次编辑

1. 点击右侧 **导入固件**，选择通过完整结构校验的 GR4 `.bin` 文件。
2. 在左侧选择 **裁切比例** 或 **关机图案**，完成编辑。
3. 点击 **保存修改**。修改比例后，须先点击比例旁的 **确认**。
4. 首次生成前，打开 **更多 → 生成设置**，配置 LLVM 并点击 **检查并保存**。
5. 点击 **生成固件**，阅读并确认使用要求，再下载固件与构建清单。

生成栏的 **支持刷回低版本固件** 默认开启。点击开启时会提示：刷入低版本回退固件前，请先在相机执行 **相机设置 → 重设 → 重设为出厂设置**，否则功能丢失可能导致菜单卡死。该选择只作用于新生成的固件，须先成功安装带此改动的固件才可能影响后续更新；离线检查不代表实机刷入成功。

### 导入 XMP 并生成滤镜

公开版的 XMP 规则与研究版一致：支持包含完整颜色数据的 Adobe Camera Raw Look/Profile，包含全局曲线和颜色表；普通 Develop 调整、只引用外部 Stubbed Look 的文件，以及局部蒙版、修复、镜头模糊等内容会被标记为不完整。打开 **滤镜** 后先点击 **新增滤镜**，从原厂滤镜复制一个模板创建可编辑槽位；原厂槽位保持只读。先在色彩区 **设置 → 转换方式** 选好链路，再在自定义槽位点击 **导入 XMP**，导入即启动转换；已有 XMP 切换链路时须点击 **重新转换**。全新安装会自动把仓库内置的 3 张 GR IV DNG 复制到本机用户数据目录，并指定 `R0000398.DNG` 为独立检查样片；已有校色数据不会被覆盖，仍可在校色设置中换成自己的样片。样片合计约 97 MiB，会随源码下载；原始文件不会上传。

“转换方式”默认 **本地模拟**，使用 LibRaw/OpenCV 近似渲染；Windows 还可选择 **Lightroom Classic** 作为目标渲染链路。选择 Classic 后，需自行安装并打开 Lightroom Classic，在 **增效工具管理器** 启用 **GR4 Firmware Bridge**；程序会准备桥接请求，不会自动启动 Classic。两种目标随后都进入软件域拟合，生成候选机内颜色资源。目前尚未完成真实 Lightroom 渲染或相机实测，结果不能当作机内效果验证。详细步骤见[校色说明](docs/CALIBRATION.md)。理光 [GR IV 产品页](https://us.ricoh-imaging.com/product/gr-iv/)和[规格页](https://www.ricoh-imaging.co.jp/japan/products/gr-4/spec/)说明相机可记录 14 位 DNG，但目前公开页未提供可直接下载的 GR IV DNG 样片；旧 GR DIGITAL IV 样片页提供的是旧机型 JPEG。仓库内置样片是作者提供的 GR IV 文件，不是理光官方样片，也不代表官方色彩结果。请为其他 DNG 和 XMP 确认使用、修改和再分发权利。

柔焦／柔光专项按维护约定冻结，不随公开版滤镜和校色链路启用；公开版不承诺该专项功能。

操作示例、图片显示方式和备份恢复步骤见[完整使用指南](docs/USAGE.md)。

## 常见问题

| 问题 | 处理方法 |
| --- | --- |
| 提示 Python 版本不正确 | 使用 64 位 Python 3.12；当前启动器不接受其他版本 |
| 浏览器没有自动打开 | 手动打开启动窗口显示的网址，并保持该窗口运行 |
| “生成固件”不可用 | 确认输入兼容、所有比例已确认，并完成 LLVM 配置 |
| 缺少 `llvm-objcopy`、`llvm-nm` 或 `ld.lld` | 安装包含这些组件的完整 LLVM 工具链，见使用指南 |
| 导入编辑备份失败 | 先导入备份对应、SHA-256 完全一致的输入 BIN；备份本身不含该文件 |
| 关机图片出现黑边或被裁掉 | “完整显示”保留内容并补黑边；“铺满画面”填满区域并裁掉超出部分 |
| 首次生成的版本为什么是 `.10` | 本项目预留 `.8` / `.9`；后续按当前输入与本机版本记录的最高编号加一 |

更多说明见[故障排查](docs/USAGE.md#故障排查)。
