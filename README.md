# 固件编辑器

**gr-custom-tool** 是一款在本机浏览器中运行的编辑工具，用于调整兼容固件的裁切比例与关机画面。

[快速开始](#快速开始) · [使用指南](docs/USAGE.md) · [常见问题](#常见问题) · [支持作者](#support) · [使用协议](web/terms.html)

## 功能

| 功能 | 当前状态 |
| --- | --- |
| 裁切比例 | 新增自定义比例、预览、命名和排序 |
| 关机画面 | 导入图片、预览、选择显示方式、管理图案 |
| 编辑记录 | 保存草稿、导入与导出编辑备份 |
| 版本历史 | 查看版本与来源、载入编辑、生成回退文件 |
| 滤镜 | 开发中；当前公开版不包含滤镜编辑或校色代码 |

本工具只生成文件，不会自动刷写设备。仓库不提供原厂固件或关机画面素材；请使用自己有权使用的输入。

## 兼容范围

- **可生成：**已适配的官方原版 `1.11.10.7`，以及当前公开版生成的兼容文件。
- **尚未支持生成：**其他官方版本、旧完整版编辑器生成的文件，以及不匹配当前布局的输入。
- **电脑：**Windows x64、macOS Apple Silicon / Intel；均需 64 位 Python **3.12**。

官方输入按文件内容识别，仅版本号相同不足以确定兼容性。当前公开版尚未完成独立端到端及实机验收，macOS 尚未实机验证；文件生成成功不代表刷入、启动或设备功能正常。

## 快速开始

### 1. 准备环境

安装 **64 位 Python 3.12**，下载源码并解压到可写目录。GitHub 发布后，可在仓库页面选择 **Code → Download ZIP** 获取源码。

生成文件还需要 LLVM 工具链，首次配置方法见[使用指南](docs/USAGE.md#安装与启动)。编辑前不必先配置 LLVM。

### 2. 启动工具

| 系统 | 操作 |
| --- | --- |
| Windows x64 | 双击项目目录中的 `start.cmd` |
| macOS | 在项目目录打开终端，运行 `sh start.sh` |

首次启动会自动创建 `.venv` 并安装固定版本的 Python 依赖，需要联网。随后自动打开浏览器；默认地址为 `http://127.0.0.1:8787`，端口被占用时会更换，请以启动窗口显示的网址为准。

关闭启动窗口或按 `Ctrl+C` 停止服务。下次运行同一启动器即可继续使用。

### 3. 完成第一次编辑

1. 点击右侧 **导入固件**，选择兼容的 `.bin` 文件。
2. 在左侧选择 **裁切比例** 或 **关机图案**，完成编辑。
3. 点击 **保存修改**。修改比例后，须先点击比例旁的 **确认**。
4. 首次生成前，打开 **更多 → 生成设置**，配置 LLVM 并点击 **检查并保存**。
5. 点击 **生成固件**，阅读并确认使用要求，再下载固件与构建清单。

操作示例、图片显示方式和备份恢复步骤见[完整使用指南](docs/USAGE.md)。

## 常见问题

| 问题 | 处理方法 |
| --- | --- |
| 提示 Python 版本不正确 | 使用 64 位 Python 3.12；当前启动器不接受其他版本 |
| 浏览器没有自动打开 | 手动打开启动窗口显示的网址，并保持该窗口运行 |
| “生成固件”不可用 | 确认输入兼容、所有比例已确认，并完成 LLVM 配置 |
| 缺少 `llvm-objcopy`、`llvm-nm` 或 `ld.lld` | 安装包含这些组件的完整 LLVM 工具链，见使用指南 |
| 导入编辑备份失败 | 先导入备份对应、SHA-256 完全一致的输入 BIN；备份本身不含该文件 |
| 关机图片出现黑边或被裁掉 | “完整显示”保留内容并补黑边；“铺满画面”填满区域并裁掉超出部分 |
| 首次生成的版本为什么是 `.10` | 本项目预留 `.8` / `.9`；后续按当前输入与本机版本记录的最高编号加一 |

更多说明见[故障排查](docs/USAGE.md#故障排查)。
